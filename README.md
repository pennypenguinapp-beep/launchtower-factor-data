# LaunchTower Factor Data

Free sample: 151 US large-cap stocks scored on momentum, volatility, and quality.

- **Data:** `factor_scores_151.csv` — ticker, 12m/3m momentum, volatility, quality score, composite score.
- **Methodology:** composite = weighted blend of 12m momentum (50%), 3m momentum (20%), inverse volatility (15%), quality score (15%). Higher composite = stronger factor profile.
- **How to read:** sort by `composite_score` descending; top decile = strongest factor tilt, bottom decile = weakest.
